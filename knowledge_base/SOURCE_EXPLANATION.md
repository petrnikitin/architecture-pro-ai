# Источник текстов в базе знаний Cyber Nexus

## Откуда взялись тексты?

### Метод 1: Прямая генерация (использован в проекте) ✅

**Источник:** Написаны автором проекта на основе общедоступных знаний о вселенной Star Wars.

**Процесс:**
1. Использованы факты из публично доступных материалов (фильмы, книги, вики)
2. Информация пересказана своими словами
3. Все термины заменены согласно словарю `terms_map.json`
4. Тексты записаны напрямую в скрипты генерации

**Файлы:**
- `scripts/generate_knowledge_base.py` - 19 документов
- `scripts/generate_additional_docs.py` - 14 документов

**Преимущества:**
- ✅ Быстро (не нужен интернет)
- ✅ Надёжно (нет зависимости от внешних ресурсов)
- ✅ Контролируемо (точно знаем содержимое)
- ✅ Легально (пересказ своими словами)

**Недостатки:**
- ❌ Ограниченный объём (33 документа)
- ❌ Только ключевые персонажи/события

---

### Метод 2: Скачивание из фандома (НЕ использован, но доступен)

**Источник:** starwars.fandom.com (Wookieepedia)

**Процесс:**
1. Скрипт `fetch_fandom_pages.py` скачивает HTML страницы
2. Извлекается чистый текст (без форматирования)
3. Сохраняется в `knowledge_base/raw/`
4. Скрипт `replace_terms.py` заменяет термины
5. Результат в `knowledge_base/processed/`

**Почему НЕ использован:**
- ⚠️ Нестабильность (фандом может блокировать боты)
- ⚠️ Юридические риски (копирование контента)
- ⚠️ Требует интернет и время
- ⚠️ Может измениться структура сайта

**Когда использовать:**
- Нужно больше документов (100+)
- Требуется больше деталей
- Готовы разобраться с правами на контент

## Как проверить источник?

### Проверка содержимого:

```bash
# Смотрим любой документ
cat knowledge_base/processed/characters/Xarn_Velgor.md
```

**Вы увидите:**
- ✅ Термины Cyber Nexus (Xarn Velgor, Synth Flux)
- ✅ Сюжет, похожий на Star Wars, но с другими названиями
- ✅ Логичные связи между документами

### Проверка уникальности:

```bash
# Ищем оригинальные термины (должно быть 0 результатов)
grep -r "Darth Vader" knowledge_base/processed/
grep -r "The Force" knowledge_base/processed/
grep -r "Death Star" knowledge_base/processed/
```

**Результат:** Пусто (все термины заменены) ✅

## Откуда LLM "знает" Star Wars?

LLM (например, GPT-4) обучалась на огромных датасетах, включающих:
- Wikipedia
- Книги (в том числе Star Wars романы)
- Статьи и обзоры
- Фандомы и вики

**НО!** LLM НЕ знает:
- ❌ "Xarn Velgor" (нет в интернете)
- ❌ "Synth Flux" (нет в интернете)
- ❌ "Nexus Dominion" (нет в интернете)

**Поэтому** без RAG модель не сможет ответить на вопрос "Who is Xarn Velgor?"

A: Да! Просто допишите в `scripts/generate_additional_docs.py` новые тексты.

A: Да, т.к. это полностью новая вселенная с новыми названиями.

**Q: Нужно ли запускать fetch_fandom_pages.py?**
A: Нет, текущая база уже готова и достаточна для проекта.
