# Knowledge Base: Cyber Nexus Universe

## Описание

Уникальная база знаний для RAG-бота, основанная на вселенной **Star Wars** с полной заменой всех ключевых терминов.

**Исходная вселенная:** Star Wars
**Новая вселенная:** Cyber Nexus

## Цель создания

Создать корпоративную базу знаний, которую LLM не встречала при обучении. Это позволяет честно протестировать механизм RAG и убедиться, что модель использует именно векторный индекс, а не свою память.

## Структура

```
knowledge_base/
├── raw/              # Исходные тексты (до замены терминов)
├── processed/        # Обработанные тексты (после замены)
├── terms_map.json    # Словарь замен терминов
└── README.md         # Этот файл
```

## Статистика

- **Количество документов:** 30+
- **Категории:** Персонажи, Организации, Планеты, Технологии, События
- **Заменено терминов:** 100+

## Использование

1. Документы в `processed/` готовы для загрузки в RAG-систему
2. Используйте `terms_map.json` для обратной трансляции ответов (опционально)
3. При тестировании задавайте вопросы про **Cyber Nexus**, а не Star Wars
